# iPhone debug flags

How to drive the iPhone app in a test run: the flags, the first run and reminders, and the simulator rules.
The Mac's flags and the evidence each change needs are in [docs/verification.md](../docs/verification.md).

The Mac's `TOMO_*` flags work when passed through `simctl` with a `SIMCTL_CHILD_` prefix, e.g. `SIMCTL_CHILD_TOMO_STAGE=3 xcrun simctl launch tomodachi com.zenbujapanese.tomo`. `TOMO_CARD_COUNTDOWN=<seconds>` fakes "nothing waiting, next words in that many seconds" for the Lock Screen card and the widget. To see the card without running the app, open `Widgets/TomoVisitLiveActivity.swift` in Xcode and show the canvas (⌥⌘↩): its previews show the Lock Screen card and the expanded, compact and minimal Dynamic Island, ready and waiting. On a simulator or phone, play a round, then go Home to see the Dynamic Island (long-press it to expand) or lock the device (⌘L in Simulator) to see the card. The first run: `TOMO_ONBOARDING=<step>` opens it at a step (hatch, round, result, visits, rhythm, quiet, notify, widget, lockScreen, ready, welcomeBack), `TOMO_AUTOPLAY=1` plays it through; a fresh install shows it from the start. Reminders (TomoCore's `TomoReminderCenter`): `TOMO_REMINDERS_LOG=1` writes every pending reminder to the system log (`xcrun simctl spawn <device> log show --last 5m --predicate 'eventMessage CONTAINS "Tomo reminder"'`), and `TOMO_NOTIFY_PROVISIONAL=1` asks for quiet delivery instead of showing the prompt, since nobody can tap Allow on a headless simulator (`simctl privacy` has no notifications service); the reminders' settings are on `TOMO_OPEN_WINDOW=settings`. Agents run the simulator headless (`xcrun simctl boot`, never Simulator.app) and mute Tomo with `xcrun simctl spawn tomodachi defaults write com.zenbujapanese.tomo soundEnabled -bool false`. Right after installing, give iOS a few seconds before tapping Play or a choice on the card: until it has indexed the app's actions, the tap fails ("There is no metadata for TomoPlayIntent" in the system log). `TOMO_OPEN_WINDOW=<screen>` (tomo, words, settings, about, startOver) opens a tab; launch with `simctl launch --terminate-running-process`, or a copy the system already started keeps running without your flags.
